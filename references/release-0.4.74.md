# Indexed AX metadata and one original .73 PRE reference failure

The complete Word inventory reads each AX window by its current index and
queries the explicit AXTitle, AXRole and AXSubrole attributes. It retains all
document, window, active, modal, minimized and sheet metadata, bounds the AX
scope and rechecks each title and the window count. Missing or changed data
still fails the inventory. An AX window count of zero never changes the Word
document count or establishes ownership, readiness or ordinary release.

The original .73 PRE failed at `my clean(subrole of aw)`, with System Events
error -1728 for `文件1  -  已復原`. A later locked diagnostic could read that
property as well as its indexed attribute. The historical underlying cause
remains UNKNOWN; the access change is not proof of a permanent permission
defect, a reproduced race or reliable recovery in every future window.
The first complete candidate read was refused with AX_SET_CHANGED and retained.
Two subsequent complete read-only observations matched, including the unsaved
UNKNOWN document. These successful observations do not erase that refusal.

Every original Python pin and four critical drivers must agree. The old source
is read, never imported or changed. The fixed original read-only script has SHA
`c07e5b41ea7a060c4d483121bfbfddaad3a418cb77110bd3221225474c549957`.

Only the observed System Events diagnostic, original script location
2817:2837 and exact recovered-window descriptor are supported. Another -1728,
locale, window, application, script, partial stdout, launch, native intent,
output, staging, live child or changed evidence remains PENDING. All four PRE
files, original no-launch application bindings and original child result are
required. The .70 binding-failure and .72 Word -1712 profiles retain their
original boundaries.

Use `scripts/word_preinput_recovery.py preview --root <original-root>
--ticket <original-ticket>` through the new complete controller with Python
`-BE`. The read-only preview returns its exact plan SHA and changes no queue.
Only the authenticated original actor may apply that SHA. Fresh locked
verification and CAS close this single restricted ticket as FAILED_PREINPUT,
retaining its invocation, token, nonce, original result and evidence.

Closeout grants no replay, invocation refund, legacy resource release, foreign
save/close, citation Refresh or manuscript acceptance. A subsequent approved

FIFO admission. Installation and actual original-actor closeout are separate
