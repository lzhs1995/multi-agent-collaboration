# Release 0.4.77

This release adds an explicit semantic contract only for separately approved new
owned initial Word revision jobs. See [the complete contract](word-semantic-contract.md).
The child verifies both source views before native application loading and after
the tracked save/reopen, then checks zero revisions and corresponding source
semantics in the clean outputs. The original exact revision-header comparison
remains unchanged for jobs without the optional mode.

Full table structure, effective formatting, field instructions/results, note
relationships, settings, custom properties, custom XML and media remain protected. Exactly declared running
PAGE caches accept only bounded canonical positive decimal digits, with a
nonempty final accepted cache. Tracking/markup state and raw revision headers
are recorded separately. Unsupported revision shapes refuse safely.

Zero character-unit indentation follows Word's documented reset/inheritance
rules. Custom tab stops accumulate across layers with position overrides and
clear; an empty direct set cannot erase inherited stops. Legacy zero aliases
with nonzero lengths and ambiguous duplicate positions remain conservative.
Endpoint and actual driver controls reject format changes before native loading
and before tracked output can proceed to accept/reject.

Unproved cross-layer first-line/hanging and modern/legacy side mixtures retain
ordered cumulative slot values, permitting numeric spelling and duplicate
materialization only. Active hanging indents with explicit tab clears refuse
until their implicit-stop precedence is established by native evidence.

This does not reopen the failed original CMA ticket, authorize Zotero Refresh,
change ordinary FIFO or release foreign documents. Native rendering, actual
adoption and scientific acceptance require separate evidence. Existing attempts
remain under their immutable controllers.

The unchanged protected ordinary-message driver is explicitly recognized for
0.4.77 by its existing exact SHA. Future versions remain refused; old attempts,
original controllers and the single reviewed zero-input recovery budget remain.
