# Release 0.4.82

The official macOS Codex release filename is authenticated through the user's
canonical launcher, executable identity, content digest and explicitly refreshed
signature cache. Missing, stale or unsafe cache records require refresh; ordinary
identity reads never invoke codesign. Refresh, digest verification and publication
share the caller's monotonic deadline. The cache protects against other users and
accidental writes; it is not a security boundary against another process with the
same UID. Warm observations do not establish the cold-page 2.5-second limit.

An official TUI without the original foreground observer can establish its
current user thread from exactly one live writable rollout descriptor. The
descriptor, inode, CLI user metadata and a complete post-birth record are checked
before and after reading. Native token-usage records require both payload thread
and session aliases to match that descriptor/metadata thread. Resume arguments,
titles and file mtime never select
the caller. A required or malformed original foreground observer cannot fall
back. Public proof identifies this distinct evidence source and native record.

The Word broker supports a separately pinned native successor approval chain
for the existing OWNED_REVISION_ROUNDTRIP capability. It validates the actual
applied parent, five native messages, complete intervening span and unchanged
job scope in an isolated original controller. This does not transfer the ordinary
resource owner or add Zotero Refresh authority.

`word_native_cua_closeout.py` can close the exact consumed .77 owned-stage
failure after its separately authorized native close has been independently
proved. The current approved actor checks the complete original evidence,
drained group, unchanged owned file, current Word identity and absent owned FD.
It locks the original resources, archives the exact pending bytes and compares
every original ticket field inside the database transaction. Only the terminal
status changes; the failure, invocation, ordinary owner, FIFO and spent native
slots stay fixed. Recovery retires only the same archived pending pointer and
never calls Word again.

The opt-in direct-CUA roundtrip verifier includes the reviewed paired pre-export
filesystem query and query-time check. Its unchanged helper is part of this
complete release. The verifier supports its declared direct-CUA shape; unsupported
wrappers and missing action evidence stay pending. It grants no resource or
application permission and does not replace the existing script-driven Word
validators. Old query evidence retains its original helper/controller.

Source checks, complete-release publication, installation, current native caller
authentication, actual application execution and final manuscript acceptance
have separate receipts. Original .77/.79/.80/.81 controllers and attempts are
retained.
