# Release 0.4.80

The prospective [causal context observer](model-context-causal.md) joins every
native result in an immediate request batch by causal IDs and the complete
canonical result-batch SHA. Actual append offsets remain provenance and no
longer select membership for this separate observer.

The full public consumer is covered by 18 causal controls; 33 sequential
controls preserve the original default and full-body contracts. Four frozen
native batches exercise the real join and wrong-base, wrong-parent and
missing-whole-batch negative controls. These four cases are component
regressions, not official-window runs or full-body acceptance.

The original v1 and sequential observers, native receipts, old controllers,
failed u24 window, CAS, inputs, clocks and resource owners remain unchanged.
Publication, installation, current loading and a future experiment require
their own evidence. This release issues no application or resource action.

Only the already reviewed exact ordinary-message driver SHA is registered for
.80. Changed driver bytes and the next unreviewed version remain refused.
