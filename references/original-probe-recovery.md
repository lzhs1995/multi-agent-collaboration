# Original probe recovery

Narrow Claude panes can clip a git footer before its closing parenthesis or
replace the progress count with an ellipsis. A footer parser that requires the
missing suffix can return the footer as composer text, refusing a legitimate
probe cleanup. This is an input classifier failure, not an API failure.

Recognize these measured shapes only after the complete editor borders and
provider footer have been verified. An identical line inside the editor remains
a draft. Unknown trailing lines and shell prompts remain closed. Current Claude
activity is the status immediately above that editor, optionally separated by
the measured goal indicator; do not treat an old spinner above a new reply as
current activity. These classifications do not prove delivery.

Preserve the failed `bridge-test-evidence.json` and identity gate. On a fresh
idle receiver, run `mac_harness.py bridge-clear-observe` with the original task,
explicit UUIDs, artifact root and a distinct `--bridge-clear-recovery` path.
It sends no input and records the current empty composer separately. Handshake
rechecks that observation and the unchanged original evidence before sending.

Only if the original probe or its exact prefix remains may
`bridge-clear-token` erase it. The command records an exclusive journal before
input and checks the original evidence, live UUIDs, idle state and expected
prefix before every End/Backspace. A changed draft, uncertain key result or
existing journal stops input. It never pastes, presses Enter/Tab or writes an
ACK. Follow successful cleanup with a separate empty observation and a real
handshake. Do not overwrite the failure, repeat bridge-test or replay cleanup.

`test_bridge_clear_recovery` and `test_bridge_clear_token` cover clipped footer
shapes, same-shaped drafts, current/history spinners, foreign text, changing
identity/evidence, uncertain key results and journal replay. Mocked transport
tests establish these guards only; installation and live handshake/callback
acceptance require their own evidence. Keep each in-flight controller fixed.
