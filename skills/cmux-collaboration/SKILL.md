# cmux outward collaboration

Use cmux to locate and coordinate independent terminal teams. For a nested
research project, each chapter has a cmux workspace containing its Herdr team;
chapter supervisors report to one senior supervisor. Pure cmux teams remain
supported and do not need Herdr installed.

Read the [common contract](../../references/collaboration-contract-core.md) and
[profile rules](../../references/collaboration-profiles.md). For multiple teams,
also read [nested coordination](../../references/nested-research-coordination.md)
for the four modes, 60-second progress visibility and five collaboration rules.
For official Codex startup or caller failures, read
[official client compatibility](../../references/official-codex-caller.md).
Keep installation selection, foreground authentication and task acceptance separate.

1. Resolve the existing task and participants before dispatch. Pin workspace,
   pane, surface and original native session for an independent terminal. For a
   Herdr team, also pin the service selector/endpoint and inner supervisor's pane,
   terminal and native session. An outer surface identifies a container, not its
   current inner recipient.
2. Coordinate chapter milestones, interface questions, resource conflicts and
   accepted deltas through supervisors. The senior supervisor owns whole-project
   integration; chapter supervisors retain their chapter outputs. Direct peer
   discussion is useful when scoped, but does not silently reassign ownership.
3. Select delivery for the actual recipient. Independent native cmux terminals
   use the [cmux profile](../../references/cmux-collaboration-profile.md) and
   [verified delivery](../../references/verified-compose-delivery.md). For an
   inner Herdr supervisor, use the [Herdr skill](../herdr-collaboration/SKILL.md)
   with its explicit service selector. Never type into the outer multiplexer
   and assume the intended inner pane receives the message.
4. Preserve drafts and original attempts. Both directions need actual native
   reception/body-reading evidence; a file mailbox or queued notice alone does
   not prove that an idle agent woke or consumed the task. Observe the original
   attempt after an uncertain result; do not resend it to manufacture a receipt.
5. Read and decide on a chapter's versioned deliverable before dispatching
   dependent integration work. Return the scoped decision and remaining issues;
   do not require an ACK of that decision. Global Word/Zotero and account leases
   remain shared across workspaces and Herdr services.

New task guidance does not migrate an existing cmux controller, callback or
continuing registration. Use the [complete cmux guidance](../../references/cmux-legacy-entry.md)
only for the applicable protocol. Reading this entry does not enroll teams,
start agents, install hooks or authorize changes to another team's files.
