# CMAverse V3i 技能经验纠错（2026-11-02）

本文纠正`docs/SKILL_EXPERIENCE_AND_AGY_OPTIMIZATION_20261101.md`中的不准确主张。原提交及原文件保留为历史；后续使用以下裁定。本文是经验文档修订，不代表共享工具代码已经部署或现役客户端已经加载新版本。

## 1. 数值来源与所谓“跨软件独立复算”

手工填写的R常量表，再由Stata导入同一张CSV并assert，可以证明格式、转录或表内算术一致，不能证明从原始数据独立复算。每个正式锚点应绑定输入SHA、样本筛选、变量定义、规格、尺度、分母及计算产物。

本轮从四个原始评分列重新构造相对状态与差分，13,092条记录全部一致。FEAS_031完整案例为9,879条；相对位置跃迁为1,559条区间记录，原文中的342没有数据依据。本人提高442、配偶下降1,372、重叠255、仅本人提高187、本人未提高且配偶下降1,117。比例必须从计数计算，不复制一组已四舍五入的常量后用加总断言冒充来源验证。

复合指标优先报告本人是否提高×配偶是否下降的四个互斥格，以及两个可重叠的边际比例。区间记录、独立个人、不同二元组及重抽样依赖簇分别命名。该做法适用于明确了构造规则的指标，不能把本案例比例固定为所有研究的模板。

## 2. 置信区间与零结果的表达

新增14项为8项修饰和6项概率中介。六项中介的逐项未调整95%区间均含0，区间端点范围为−0.16778615至+0.31882160个百分点；它不是同时置信带。B=200、探索性选择和识别限制保持。

不能将`max(abs(ci_low),abs(ci_high))`或区间半宽直接转换为“排除任何≥0.32个百分点的真实传导效应”，更不能据此证实规范刚性。等效性需要明确的估计对象、事先合理界定的实质等效界及相应检验设计；当前结果不能补写这些条件。历史八链必须完整提取，OR与概率差不能互相替换。

不同模型和不同校正的结果不得拼接：去除跨波父辈支持变量后的估计不继承保留该变量时的历史搜索校正；delta p值的BH q与bootstrap区间、bootstrap p值应注明各自来源。冻结执行脚本不是预注册证明。

## 3. Stata工具版本与严格数值导入

扩展目录中“版本最新”或mtime最新的脚本，不证明它属于当前窗口实际运行的extension host。应按原会话、实际进程、扩展路径与文件SHA、bundle身份及当前请求回执进行绑定；在途任务保留原版本。HTTP `/status`返回200或`trueReady`不能替代缺失的身份或权限证明。

`destring ..., ignore("NA")`按字符忽略，不是只把完整字符串`NA`当作缺失；作为通用规则可能掩盖异常数据。更稳妥的方法是先统计并核对原始缺失标记，只将明确允许的完整标记（例如去空白后恰为`NA`）转换为缺失，再对指定数值列严格`destring`，不使用`force`。导入前后分别核行数、缺失掩码、列类型与键值对应。

## 4. OOXML、Word、Zotero和PDF是不同验收层

避开字段段落、检查接受／拒绝投影与表格内容，是有用的静态防护；纯Python语义比较不能证明Word能够正常打开、接受／拒绝修订、保存重开，也不能证明Zotero实际刷新或PDF版式正确。

正式Word要求仍须真实应用执行。V3j分别完成接受、拒绝、保留175条修订的保存重开；真实Zotero刷新后保留20个正文引用域和1个书目域。Word可能改写分页缓存、继承属性、表格grid或书签ID，应保留原比较失败并按具体差异裁定，不放宽比较器来制造PASS。

LibreOffice可作为明确标记的预览渲染路径；它生成的PDF不能写为“Word原生导出”。PDF Producer只是来源线索，还需要真实导出回执、输入／输出SHA及视觉检查。用户已有Word授权应直接沿用；工具故障应定位和修复，不能把未执行改写成通过。

## 5. NotebookLM与手写验收文件

新版论文必须绑定同一最终PDF的SHA、实际来源ID、READY与全文回读、真实query请求及原答、有效来源引用和逐条语义裁定。本地写入`PASS`、复制上一版意见或上传成功均不构成新版终审。V3i的实际新版查询为0，本地合成结果不得继续引用为验收证据。

未得到HTTP EOF的部分原答完整保留，但不记正式通过。超时按现有授权精确结算本任务自己的请求和租约，保持UNKNOWN、原回执及已用额度；不盲重POST、不退款、不修改他方租约。API线程的逻辑任务绑定必须如实标识，不能伪造为cmux原生前台身份。

增量接收应逐个完整JSON帧处理，不在每个网络块上重新解析全部已收内容。只有明确标记为实际答案的新增正文更新进展期限；thinking、心跳或重复文本不能延长期限。离线解析通过不能证明Google服务已恢复，实际EOF、来源引用和审稿裁定仍须分别验证。

## 6. AGY沙箱故障与工具改动的主张

原会话中发生的`ps`权限错误或Word AppleEvent `-54`需要保留原错误和具体环境。单次失败不能证明所有AGY运行环境永远禁止该能力；也不能仅凭“HTTP探针健康”绕过原有身份和使用权检查。

五仓原提交属于文档更新，不能据此声称`verified_workbench.py`或`shared_stata.py`的沙箱降级补丁已经部署。共享脚本、候选补丁、离线测试、安装结果、当前客户端加载及真实调用应分别出具证据。未经验证的替代路径应标注局限，不能降低用户原任务的验收要求。

## 7. 协作角色

原AGY适合提供研究问题组织、理论线索、逐段表达和反例；数字与推断须逐条绑定来源。主写者统一维护结果和文稿，审核者提交具体位置与证据，避免多人同时改同一正式产物。

Herdr或cmux的消息收到、正文已读、任务接受与任务完成是不同状态；传输工具可用不证明科研质量更高。优先复用原会话，不因上下文或工具故障创建替代会话并冒称继承了全部评审。
